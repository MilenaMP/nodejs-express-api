# Node.js Express API

API REST desenvolvida com **Node.js, Express e TypeScript**, com foco no aprendizado prático de desenvolvimento back-end, estruturação de projetos e construção de serviços web.

## 🚀 Tecnologias

- Node.js
- TypeScript
- Express
- tsx
- tsup

## ⚙️ Configuração e execução

### Pré-requisitos

- Node.js
- npm

### 1. Clone o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2. Acesse a pasta do projeto

```bash
cd nodejs-express-api
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Configure as variáveis de ambiente

Crie um arquivo `.env` na raiz do projeto:

```env
PORT=3333
```

### 5. Execute o projeto em desenvolvimento

```bash
npm run start:dev
```
